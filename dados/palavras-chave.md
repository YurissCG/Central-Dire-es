# Mapa de palavras-chave

Uma página, uma intenção. Duas páginas mirando o mesmo termo se canibalizam e as duas caem.

Não existe dado de volume aqui porque não temos ferramenta paga conectada. A priorização é por intenção de compra, que para negócio local acerta mais que volume estimado. Se o Keyword Planner for conectado depois via `/seo google`, revise a coluna de prioridade.

## Camada 3. Sintoma, o maior volume real

O cliente não sabe o nome da peça. Ele sabe o que o carro está fazendo. É a camada com mais busca e a que quase nenhuma oficina disputa.

| Termo | Página |
|---|---|
| direção pesada o que pode ser | `/sintomas/volante-pesado` |
| barulho ao virar o volante | `/sintomas/barulho-ao-virar-o-volante` |
| carro puxando para um lado | `/sintomas/carro-puxando-para-um-lado` |
| volante vibrando em velocidade | `/sintomas/volante-vibrando` |
| carro pulando muito suspensão | `/sintomas/carro-pulando-nos-buracos` |
| vazamento de óleo direção hidráulica | `/sintomas/vazamento-de-oleo-na-direcao` |
| pneu gastando de um lado só | `/sintomas/pneu-gastando-torto` |
| freio rangendo o que pode ser | `/sintomas/freio-rangendo` |
| folga no volante | `/sintomas/folga-no-volante` |
| barulho na suspensão ao passar em buraco | `/sintomas/barulho-em-buraco` |

Padrão de cada página de sintoma:

1. H1 com a pergunta como a pessoa digitaria
2. Resposta direta em 130 a 170 palavras, autocontida, é o bloco com chance de ser citado em busca com IA
3. `Causas mais comuns`, em lista
4. `O que fazer agora`, com o que dá para checar sozinho
5. `Quando é urgente`, honesto, sem inventar urgência para empurrar serviço
6. Link para o serviço correspondente
7. CTA de WhatsApp com o sintoma já na mensagem

O item 4 é contraintuitivo e é justamente o que constrói confiança. Dizer "confira o nível do fluido, é um minuto e às vezes resolve" faz o visitante voltar quando o problema for de verdade.

## Camada 4. Pergunta comercial

Vão para `/duvidas` e para o bloco de perguntas de cada serviço.

- quanto custa arrumar direção hidráulica
- quanto custa trocar caixa de direção
- peça remanufaturada é boa
- vale a pena reparar ou trocar a caixa de direção
- de quanto em quanto tempo alinhar o carro
- qual a diferença entre alinhamento e balanceamento
- direção elétrica é melhor que hidráulica

Preço é a busca mais frequente e a mais evitada pelos sites de oficina. Se o dono autorizar publicar faixa de preço, essa página vira a de maior conversão do site. Se não autorizar, explique o que determina o preço, que é peça, modelo e estado do componente, e chame para o orçamento. O que não pode é ignorar a pergunta.

## O que não fazer

- Página por bairro sem operação real ali. Isso é doorway page e o Google pune. Máximo de 3 páginas geográficas, cada uma com conteúdo próprio
- Repetir a keyword além do natural. Densidade não é métrica desde muito antes deste projeto
- Mirar termo nacional tipo "caixa de direção" sem qualificador. É disputa com portal de peça e não traz carro para o pátio
- Criar página nova sem checar se um termo já está coberto por outra
